Manual de Usuario - Aplicativo MIPRES

1. Introducción

Este manual describe cómo utilizar el aplicativo para la gestión de MIPRES, incluyendo la generación de tokens, entrega en ámbito, reporte de entrega y facturación.

El objetivo es guiar al usuario final en el uso correcto de la herramienta para asegurar la correcta radicación de facturas.

2. Inicio de Sesión y Generación de Token

Para comenzar, es necesario iniciar sesión y generar un token diario. Este token es indispensable para realizar cualquier operación en el sistema.

Una vez iniciada la sesión, se debe generar el token.

3. Módulos del Aplicativo

El aplicativo se divide en tres módulos principales que siguen un flujo de trabajo específico.

3.1. Entrega en Ámbito

Este es el primer paso del proceso. Aquí se registra la entrega de los servicios o tecnologías en salud.

Se deben diligenciar todos los campos del formulario con la información correcta. Al enviar la información, el sistema MIPRES devolverá una respuesta.

Respuesta Exitosa

Si los datos son correctos, la respuesta incluirá un ID y un ID de Entrega. Es crucial guardar estos dos identificadores, ya que serán necesarios para los siguientes pasos.

Respuesta de Error

Si hay algún error en los datos enviados, el sistema mostrará un mensaje de error HTTP proporcionado por MIPRES, indicando cuál es el campo o el dato incorrecto a corregir.

3.2. Reporte de Entrega

En este módulo se utiliza el ID obtenido en el paso anterior (Entrega en Ámbito) para reportar la entrega.

Al igual que en el módulo anterior, se deben completar los campos requeridos.

Respuesta Exitosa

Una respuesta exitosa generará nuevos IDs que también deben ser almacenados para el proceso de facturación.

3.3. Facturación

Este es el último paso del flujo principal. Aquí se utilizan los IDs generados en los módulos de "Entrega en Ámbito" y "Reporte de Entrega" para la radicación de la factura.

Es fundamental que todos los IDs previos se ingresen correctamente para que la factura pueda ser procesada y radicada sin inconvenientes.
